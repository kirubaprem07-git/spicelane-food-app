SpiceLane — Food Delivery App
A full-stack food delivery web application built with Python Flask and deployed on AWS EC2 as part of my cloud learning journey.

Tech Stack
- Python Flask (Backend)
- HTML5, CSS3, JavaScript (Frontend)
- AWS EC2 (Deployment)
- Ubuntu Linux (Server)

Features
- Browse food menu with categories
- Add items to cart
- Place orders with delivery details
- Beautiful red-orange theme
- Mobile responsive design
